# Karen Voice first public preview

## Outcome

People can download a free Mac dictation app, choose a local speech model, set a shortcut and put spoken words into the app they are using. The recognizable product name is Karen Voice, with green accents matching T3 Code's Grove palette.

## Included

Existing recording, speech recognition, paste, history, settings and overlay behavior. Separate bundle and data identity, original waveform branding, public source, Mac downloads, reproducible CI, release checksums and required legal notices.

## Deferred

Assistant chat, task execution, wake words, cloud accounts, automatic migration of another app's data, signed auto-updates, Apple notarization and published Windows/Linux installers. The local speech model pipeline and model download services are retained from the baseline.

## Acceptance

1. Install the correct Mac build and open it as Karen Voice.
2. Grant permissions, download a model and choose a nonconflicting shortcut.
3. Dictate into a normal text field, cancel a recording, and repeat recording.
4. Confirm green branding in light/dark mode, the recording overlay and tray states.
5. Change a setting, relaunch and confirm it persists under the Karen Voice identity.
6. Confirm legal notices are bundled and all download/update links belong to this repository.

CI validates builds and native startup. Human microphone, Accessibility and real paste acceptance remains a distinct check. The absence of Developer ID notarization is disclosed in both the README and release notes.
