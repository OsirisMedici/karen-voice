# Contributing

Karen Voice is being built in public. Open an issue in this repository with the behavior you want, why it matters, or steps to reproduce a bug. Include your operating system, app version and model. Remove personal transcripts, keys and private paths from logs before sharing them.

For a change, keep the dictation path reliable and the scope clear. Explain what users can now do, how you checked it, and what remains untested. Run the checks in BUILD.md. Use conventional commit messages. Product text goes through the existing translation files. Retain third-party notices and dependency identities.
